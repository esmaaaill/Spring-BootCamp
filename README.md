# Spring Boot Camp

This repository tracks my assignments, projects, and pull requests for the **Spring Framework Zero To Hero** bootcamp provided by CODIK Academy and instructed by Eng. Ahmed Salah. 

##  Course Content

### Module 1: Spring Framework Fundamentals
* **MySQL & JDBC:** Database design, SQL crash course, and Java database connectivity.
* **Spring Core:** Inversion of Control (IoC), Dependency Injection (DI), Beans, and Application Context.
* **Spring MVC:** Model-View-Controller architecture, JSP template engine, and DAO design patterns.
* **Hibernate ORM:** Object-Relational Mapping and mapping tables to entities.
* **Spring Data JPA:** Applying Java Persistence API for database operations.
* **Project:** Employee Management App (CRUD Application).

### Module 2: REST APIs & Spring Boot
* **Maven:** Managing dependencies and build tools.
* **Spring REST:** Refactoring backend controllers to RESTful APIs.
* **Spring Boot:** Application setup, decreasing configuration processes, and focusing on business logic.
* **Testing:** API testing and documentation using Postman, and automated user tests with JUnit 5.
* **Project:** Refactoring the Employee Management App to use REST APIs.

### Module 3: Spring Security
* **Web App Security:** Securing Spring MVC web apps and REST APIs.
* **Authentication & Authorization:** Developing default and custom login pages, defining user roles, and protecting URLs based on roles.
* **Data Security:** Storing users, passwords, and roles in the database (plain-text to encrypted).
* **JWT:** Securing web apps and APIs using JSON Web Tokens.

### Module 4: Microservices & Final Project
* **Architecture:** Building backend systems divided into integrated microservices.
* **Graduation Project:** Real-time ToDo app using Spring Boot and Microservices.
